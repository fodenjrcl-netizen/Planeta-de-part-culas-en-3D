# 🌌 Planeta de partículas en 3D

Proyecto interactivo en Three.js que renderiza un planeta dinámico con partículas y efectos visuales.

## 🚀 Tecnologías
- Three.js
- JavaScript
- HTML5 / CSS3

## 🎯 Funcionalidades
- Rotación y zoom interactivo
- Efectos de partículas dinámicas
- Diseño responsivo
